# 设定内叙利亚议会运作框架（含弹劾构思）

> **文档性质**：辅助资料，供做国策树 / 事件时参考。**设计稿 `TNO阿拉伯重置 - 埃及.drawio` 的叙利亚区段是唯一权威依据**；OTL 史料只作不冲突的质感补充，绝不套进设定。
>
> **关键设定锚（来自设计稿，已与用户确认）**：
> - 1941 同盟国入叙、库阿特利当选并对轴心国宣战；**土耳其实际控制在 1944 年**（土耳其加入轴心国、击败叙境同盟国驻军之后），非 1941。
> - 1948 阿勒颇寡头组建**叙利亚人民党**；1952 希沙克利政变被土军镇压，人民党"旋转门"执政至 **1960 年现任（基赫亚）登台**。
> - 议会**不是橡皮图章**，而是阿勒颇商帮（人民党）通过商业利益结构性掌控的正常运转机构。
> - 大国框架是 TNO **经济圈**：土耳其 / 意大利 / 美国 / 苏-红德 / 德-意，不是 OTL 美苏冷战。

## 一、OTL 参照事实（非设定，仅校准用）

### 1.1 议会怎么运作
- 一院制**众议院（Chamber of Deputies / Majlis al-Nuwwab）**，1930 宪法确立，议员任期 4 年。
- 选举制几经变：1947 两轮制单一选区男子普选（10 席预留贝都因）；1950 宪法扩为男女 18+ 直选秘密平等；1961 届 172 席、多党竞争。
- 实务极脆弱：1949、1951（施舍克里解散）、1958（并入阿联）、1963（复兴党政变后变背书机构）多次被打断。

### 1.2 席位规模时间线（1940s–60s 约 120–170 席）
| 年份 | 届次 | 席位 | 备注 |
|---|---|---|---|
| 1943 | 3rd | 124 | |
| 1947 | 4th | ≈127 | 自由党53 / 无党派50 / 国民党24 |
| 1949 | 5th | 114 | 制宪议会选出 |
| 1954 | 7th | 140 | 议会复辟 |
| 1961 | 制宪暨议会 | 172 | 退阿联后恢复 |

### 1.3 宪法时间线（**澄清：不是 1930 沿用到 60 年代**）
- **1930 宪法**：委任时期法国主导起草，1950 年被正式取代，**没有**沿用到 60 年代。
- **1950 宪法**（"独立宪法"）：1950.9.5 生效，议会制共和主体宪法，反复恢复至 1963。
- 1953 宪法：舒什克里军政府总统制，**仅活约 7 个月**，按用户口径不计入共和国主线。
- 1958–61 并入阿联：本国宪法中止；1961 退阿联后恢复 1950，1962 微调沿用至 1963。

### 1.4 法定权限
选总统（议会选，5 年）、投信任/不信任、年度预算与财政法、批准条约与协定、普通立法、质询辩论、制宪。

### 1.5 关键法案与真实案例（OTL）
- **1936 批准《法叙独立条约》**（条约批准职能落地）。
- **1948–49 Tapline 油管事件**：阿兹姆政府拿 73/108 信任票，研究对美油管过境协议；人民党/穆兄会/复兴党以"依赖美国"猛攻，阿勒颇等地示威，政府被迫撤回——**议会+反对党+商界舆论能实质卡住政府经济外交**的铁证。
- **1949 制宪议会**起草 1950 宪法。
- **1949 议会对军方质询**：防长拒到院，议会无政府出席自行开会严批军方，成扎伊姆政变导火索之一——说明当时议会敢正面怼军方。
- **1954–58 复辟期外交辩论**：拒巴格达 Pact、参万隆、挺苏伊士、拒艾森豪威尔主义；1955–56 通过 IPC/Tapline 利润分成（叙方拿 **50%**）。
- **1958 农业改革 No.161 / Law 134**：注意——这是 **UAR 国民议会通过，非叙本国议会**（设定里无 UAR，故开局时根本不存在）。

### 1.6 阿勒颇商帮 / 人民党（OTL）
- **人民党（Hizb al-Sha'ab）** 1948 成立、**以阿勒颇为基地**，领袖 **鲁什迪·基赫亚（Rushdi al-Kikhya）与纳齐姆·库达西（Nazim al-Qudsi）**——二人都在你 25 人名单里（基赫亚是你已完成的参考角色）。
- 代表阿勒颇商人/地主利益，主张与伊拉克/外约旦**关税同盟、自由贸易、商贸轴**，是亲大马士革民族集团（库阿特利）的主要对手。
- **OTL→设定映射**：OTL 商帮跟着"对自己贸易最有利的大国轴"走（当时是伊拉克轴）；设定里土耳其是宗主，则"商帮因商业利益支持亲土耳其政策"符合同一机制——只是把 OTL 的伊拉克轴换成设定里的**土耳其经济圈**。

## 二、设定内框架（以设计稿为权威）

### 2.1 时间锚与设定分歧（简化"开局前"清单）
- 假定开局 = TNO 标准 **1962.1.1**（待用户确认）；阿勒颇商帮 + 人民党自 **1949** 掌控议会至开局。
- **设定分歧**：① 1952 希沙克利被土军镇压 → **无 1953 Shishakli 宪法、无军政府中断**；② 设定**无 UAR**（土耳其是宗主）→ **1958 全套立法在开局时不存在**。
- 1950 宪法在设定里由 **1949–50 制宪会议（土方背书、人民党主导）** 产出，并**连续有效至开局**。

### 2.2 开局前 / 后法案归位表
**开局前应已落实（存量法）**
| 法案 / 机制 | 设定归位 | 理由 |
|---|---|---|
| 1950 宪法 | 开局前·生效 | 土方背书、人民党主导制宪产出，连续有效 |
| 选举法（保人民党优势/旋转门） | 开局前 | "轮替执政"制度地基 |
| 1946 劳动法 + 1948 女性普选修正 | 开局前 | 共和早期普通立法存量 |
| 油管过境利润分成协定（IPC/Tapline 类） | 开局前 | 正合商帮利益 |
| 对土经济圈关税/贸易框架 | 开局前 | 取代 OTL 伊拉克轴，亲土政策条约基础 |
| 民商/刑法典（法国法继承） | 开局前 | 稳定存量法 |

**开局后才会发生（由设定危机驱动的新立法）**
| 法案 / 机制 | 设定归位 | 说明 |
|---|---|---|
| 土地改革 | 开局后·核心冲突 | 商帮议会必然封杀，是**最大分支开关**；改革派/军方/复兴党胜则出 Decree-Law-88 类法令 |
| 国有化 / 外资法令 | 开局后 | 德经危机/石油危机触发辩论 |
| 新闻/结社/党派管制法 | 开局后 | 土方收紧或镇压时出台 |
| 宪法修正案 / 临时宪法 | 开局后 | 1964/1968 总统选举危机或复兴党分支成功 |
| 紧急状态法 | 开局后 | 骚乱/游击时启用 |
| 货币应急法 | 开局后 | 1963 叙镑贬值危机催生 |

**设定里直接不存在（对照 OTL 划掉）**：1953 Shishakli 宪法、1958 UAR 全套立法、1936 法叙独立条约（被土托管替代）。

### 2.3 议会多层日常运作模型
> 要点：OTL 议会**不是每天开全体会**。"日常运作"在 daily/weekly 层其实是**常设机器（委员会、党团、游说、土方联络）在持续转**——这才是"阿勒颇商帮掌控"的真实形态，而非只在选举日体现。

- **每年**：年度例会开幕（总统/土方总督致词）；**年度预算审议与表决**（全年核心，体现亲土经济政策）；定期大选/补缺（人民党"旋转门"但商帮基本盘不变）；年度对外条约打包批准（对土经济圈新协定）；可能触发年度信任投票或反对派借预算案发难。
- **每月**：常设委员会（财政/立法/外事/农商）月会审具体法案拨款；政府月度施政报告+质询窗；**商会/地主协会与议会党团月度协调会**（"商帮掌控"实操层）；舆论发酵。
- **每周**：人民党团周会定**投票纪律（whip）**并对齐土方"建议"；议程委员会排期；可能一次全会辩论重点案；反对派（大马士革民族派等）周度策划质询/示威联动。
- **每天**：委员会小组/法案起草；**走廊游说**（阿勒颇商界代表日常游说议员）；**土方联络官与议长、人民党领袖的日常沟通**（设定里土耳其是宗主，这是控制抓手）；媒体每日报道/泄密；议案文书。
- **每次全会（plenary）**：点名/法定人数 → 议长宣议程 → 提案一/二读 → 委员会报告 → 限时辩论 → **质询（阁员答辩）** → 表决（含信任/不信任动议）→ 公报。反对派可在此发难、煽动舆论、偶尔卡住某项议案，但多数时被党团纪律压住。

### 2.4 → 游戏机制映射建议
| 运作层 | 可触发机制 |
|---|---|
| 年（预算） | 年度预算事件：选择亲土补贴/贸易协定 vs 民生支出，影响经济与民意 |
| 月（委员会+商协协调） | 月度"商人影响力" tick：商帮好感/控制力随经济事件浮动 |
| 周（whip+土方对齐） | 周度议程事件：是否强行通过某议案，触发反对派反应 |
| 全会（质询/不信任） | 信任投票事件、不信任动议（弹劾前置）；媒体舆论变量 |
| 危机（贬值/代理博弈） | 触发分支：人民党挺过难关 vs 弹劾总统 |

## 三、弹劾总统流程构思 + 为什么 1963 弹劾可能通过

### 3.1 设计稿锚定（节点链，已读取确认）
```
1963 德国经济危机导致土耳其经济困难
  → 叙镑贬值危机
      ├─[土耳其胜利] 人民党挺过难关 → 1964 总统选举（留土耳其经济圈）
      └─[意大利胜利] 弹劾基赫亚 → 哈利德·哈兹姆（民族党-地产集团/寡头保守主义/无经济圈）
                              → 1965 哈兹姆总统病逝
                                  ├─[适得其反] 阿卜杜勒·纳赫拉维（军政府/回土耳其圈）
                                  └─[意巩固控制/豪赌成功] 穆斯塔法·西巴伊（穆兄会/意大利圈）
```
- **弹劾对象**：鲁什迪·基赫亚（设计稿顶部节点即基赫亚，且"弹劾基赫亚"以他为对象；设其为 1960 年登台的现任总统，意识形态"中间派进步主义 / 叙利亚人民党"）。
- **触发条件**：叙镑贬值危机在**意大利胜出**分支触发（意大利支持民族党激进派）。
- **弹劾后续叙事**：把政权交给一个"无经济圈"的地产寡头（哈兹姆），最终在 1965 病逝后反噬——对应"适得其反"，是意大利代理人豪赌的代价。

### 3.2 弹劾流程设计（设定内，1950 宪法为法理基础）
建议分五阶段，做成一条事件链 + 一个游戏规则的开关：

1. **发起（Motion）**：由议员联名提出（设门槛如 1/4 或 1/5 众议员联署），理由挂在"贬值危机处置失当 / 违宪 / 重大失职"。
2. **审查（Committee）**：宪法/司法委员会审议是否受理、列罪名——可做成"委员会报告"事件，决定弹劾是否成立进入全院。
3. **辩论（Plenary Debate）**：全院限时辩论，阁员（总理/外长）答辩；媒体舆论变量在此放大或压制。
4. **表决（Vote）**：设**特别多数门槛**（如 2/3）以制造戏剧性；也可走"信任投票"路径用绝对多数。表决前可插入"关键议员倒戈/弃权"的小事件。
5. **结果（Outcome）**：通过则总统下台，由议长代行或启动新总统选举（接哈兹姆节点）；未过则政府续命（但仍背负危机）。

### 3.3 为什么 1963 弹劾可能通过（7 个设定内要素）
> 默认路径即"通过"——这对应设计稿意大利胜出分支。`SYR_KIKHYA_IMPEACHMENT_FAIL` 游戏规则的定位是**玩家可强制"弹劾失败"的开关**（即反选回土耳其/人民党挺过难关分支），并非默认。

1. **代理人博弈的胜负决定票数基础**：意大利胜 = 成功扶植民族党激进派（意资、意媒、意外交背书）。民族党在议会本有席位（OTL 即以大马士革为基地的保守反对党），意方资源使其从"反对声音"升级为"可凑多数"的联盟核心。
2. **贬值危机让商帮自身受损，whip 失效**：叙镑贬值冲击阿勒颇出口商/进口商实际利润（进口成本暴涨、外债更贵）。当"保基赫亚 = 继续贬值/继续亲土"损害个别大商人利益时，部分**非核心商帮议员倒戈或弃权**，人民党团纪律松脱。
3. **土耳其自顾不暇，保体系不保人**：节点原文"1963 年德国经济危机导致土耳其经济困难"——土方无余力强力保基赫亚，更可能**默许换人保体系**：只要继任者仍留土耳其经济圈（见 1964/1968 留土圈节点），土方不介意基赫亚下台。
4. **宪法程序可用**：设定里 1950 宪法连续有效（无 1953 / 无 UAR 中断），总统由议会选、议会可倒阁——弹劾走议会多数即可，**不需要军事政变**，程序正当性强。
5. **民意与媒体放大**：贬值→物价飞涨→街头抗议（OTL Tapline 已证商界+民众可逼政府撤回）；意资背景媒体把责任钉在基赫亚政府头上，给弹劾提供"民意授权"话术。
6. **联盟数学**：民族党激进派（意支）+ 倒戈人民党议员（受损商帮）+ 大马士革民族派反对力量 + 部分无党派/军方背景议员 = 越过表决门槛（多数本就靠联盟而非铁板）。
7. **基赫亚自身处境**：作为"中间派进步主义"，在极端化危机里两头不讨好——既因贬值失去土方完全信任，又因亲土立场失去民意护盾，成为各方都能接受的**替罪羊**。

### 3.4 游戏内实现草图
- 1963 分支由**意-土代理人博弈胜负**（脚本变量 / proxy 结算）驱动。
- 意大利胜 → 触发 `弹劾基赫亚` 事件链（见 3.2 五阶段）。
- **`SYR_KIKHYA_IMPEACHMENT_FAIL` 游戏规则**：提供一个选项让玩家强制弹劾失败 → 重路由到"人民党挺过难关 / 土耳其胜利"分支（1964 总统选举留土圈）。即这是玩家对意大利分支的**退出开关**。
- 默认（无该规则 / 意大利胜）：弹劾通过 → 基赫亚下台 → 接哈兹姆节点（3.1）。

### 3.5 弹劾后的走向（接设计稿）
- 哈利德·哈兹姆（民族党-地产集团，寡头保守主义，**无经济圈**）接任 → 1965 病逝。
- 分支：**适得其反**（纳赫拉维军政府，回土耳其经济圈）/ **意大利巩固控制或豪赌成功**（西巴伊，穆兄会，意大利经济圈）。
- 叙事含义：意大利的弹劾豪赌是把政权交给一个没有经济圈支撑的地产寡头，最终反噬——这正是"适得其反"的设定闭环，也解释了为何土耳其圈在 1965 后仍能借军政府回归。
