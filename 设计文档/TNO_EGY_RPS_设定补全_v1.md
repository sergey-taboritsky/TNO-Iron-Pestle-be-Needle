# 第一编　埃及王国（EGY）

## 1.1 前史详述

**轴心胜利下的延续。** OTL 里阿里·马希尔 1940 年因亲轴心立场被英国人逼下台，此后埃及政治一直在"宫廷—华夫脱—英使馆"三角里打转。本时间线轴心国打赢了地中海战争，英国势力被逐出尼罗河下游，逼宫的那只手消失了：马希尔内阁不但没有倒台，反而成了战后埃及秩序的起点。它的合法性来自两件事——王室的信任，以及"没有把国家交给英国人"这一战时记录。但这份合法性从一开始就欠着债：轴心国胜利意味着意大利取代英国成为监护者，运河区的主权、驻军与通关收益都不再由开罗说了算；而苏丹方向，英国人撤退留下的权力真空，被马赫迪家族的复起迅速填满。

**1947 的两道难题。** 苏伊士运河是第一道。埃及要求收回运河区管辖权，意大利则把它当作地中海生命线与驻军权的底线，谈判拖成僵局；每一次退让都在议会与街头被当成卖国。苏丹是第二道：第二次马赫迪叛乱爆发后，意埃联军深入尼罗河上游平叛，军费、补给与战线同时失控。纳吉布当时在前线任旅长，查出军需采购的贪腐链条直指法鲁克国王本人，化名"一个士兵"把材料捅了出去——他一夜成为军中清流的象征，也从此被宫廷记上了账。叛乱可以靠子弹压下去，但"国王的军队在苏丹挨饿、国王的亲信在军需里发财"这件事压不下去。1947 年，运河僵局、苏丹战费与军需丑闻同时引爆，马希尔政府垮台。

**纳哈斯的短暂回光。** 接任的穆斯塔法·纳哈斯帕夏是华夫脱党最后一位能压住全党的人物。他把"运河区归还、苏丹完全统一、终止意大利监护"写成施政纲领，等于同时向罗马与宫廷宣战。意大利方面不愿看到一条由民选内阁控制的运河，法鲁克则早已把华夫脱党视为君权之敌——两者联手，纳哈斯被迫辞职。此后本地化的措辞是"纳哈斯被迫辞职之后的十余年后"，华夫脱党才重新摸到首相宝座；这十余年的起点，就是这次联手罢黜。它给埃及政治留下一条不成文的规矩：首相可以换，但**不能同时得罪宫廷与意大利**。

**1948 埃意谅解与几届过渡内阁。** 继任者选择与罗马交易：意大利承认埃及把整条尼罗河谷纳入版图、苏丹以自治领形式归开罗管辖；开罗则默认运河区与基地特权、接受意大利在财政与军备上的监护。对埃及而言这是"用运河换苏丹"，对苏丹而言则是一句口号变成了一纸判决书（见第二编）。此后数年内阁更迭频繁，萨阿德主义制度党、立宪自由党与宫廷技术官僚轮流组阁，谁也无法同时摆平议会、王室、军方与宗主。

**1953 未遂政变。** 军中的自由军官组织把这笔总账算在了君主制头上。纳赛尔、萨达特、毛希丁一系带有明显的亲德与民族社会主义倾向，主张一次性推翻宫廷—意大利秩序；纳吉布与宪政派政党往来密切，对这条路线相当反感，也与组织保持距离。政变在 1953 年败露，三名核心人物流亡海外，从此成为埃及境内只可耳语、不可组织的思想幽灵；阿卜杜勒·哈基姆·阿密尔留在军中，成为日后军政府路线的潜在载体。纳吉布虽未参与，却因声望太高、又与宪政派太近，被以"最合适的总督人选"之名外放喀土穆——名义上是重用苏丹裔名将、褒奖平叛功臣，实为把一枚定时炸弹挪出开罗。

**合并、稳定与崩解。** 政变的枪声没响成，却把政党版图重画了一遍：萨阿德主义制度党与立宪自由党在 1953–54 年间合并为**联合自由党**（ULP），把"元老—技术官僚—自由主义学者"三种气质塞进同一个屋檐，换来此后十余年的执政霸权。1955 年，无党派色彩、受宫廷信任的侯赛因·西里帕夏组阁，靠个人威望充当四派之间的仲裁者，1959.1.8 的议会选举平稳收场，埃及迎来少见的一段安静日子。1960 年西里病逝，仲裁者消失，ULP 内部的裂痕立刻公开化。萨阿德元老集团凭组织与资历胜出，易卜拉欣·阿卜杜勒·哈迪出任首相；开局时他仍在任，但已与法鲁克在闭门会议里不欢而散。

# 第二编　苏丹自治领（RPS）

## 2.1 前史详述

**两条教团的血脉。** 苏丹政治的根基不是政党，而是两条苏菲教团的世系。哈特米亚教团由大米尔加尼于十九世纪创立，盘踞东苏丹卡萨拉，自土耳其—埃及统治时代便与开罗结盟、以忠诚换特权与庇护；安萨尔（马赫迪派）源于穆罕默德·艾哈迈德·马赫迪，1881 年自命马赫迪起事，1885 年攻破喀土穆、击毙戈登，建立存续十三年的马赫迪国家，至恩图曼之战败于基奇纳。英埃共管时期，哈特米亚是受宠的亲政府教团，马赫迪家族（由其子阿卜杜勒·拉赫曼承继）则聚拢苏丹民族主义与反埃情绪，孵化出乌玛党。所有世俗政党的站位，最终都绕不开这条裂隙——本地化把它写成"苏丹政治的语法本身"。

**共管遗产。** 1920 年代，共管当局在青、白尼罗河之间铺开杰济拉灌溉工程，森纳尔水坝供水，数十万佃农被政府—辛迪加—农户三方契约缚定在棉花单一作物上，长绒棉养活了苏丹港的栈桥与兰开夏的纱厂。教育只覆盖北方：南方诸省被"南方政策"刻意封闭，交给传教士学校，与喀土穆隔绝。1930 年代起，毕业生代表大会（GGC）孕育出第一批本土知识分子，伊斯梅尔·阿兹哈里从大会秘书一路走到 1945 年创立阿什格党、1952 年扩组为民族统一党（NUP），把"尼罗河谷统一"（Wahdat Wadi al-Nil）写成党纲——主张英人的分而治之人为割裂了共饮一河的两岸。

**1947–48：从口号到判决书。** 英国势力退出后，安萨尔／马赫迪家族趁势起事，是为第二次马赫迪叛乱；意埃联军平叛，纳吉布在前线任旅长并因揭发军需贪腐成名。叛乱被压下去，却把苏丹问题推成开罗政坛的引爆点，直接压垮马希尔政府。1948 年埃意谅解谈成：意大利承认埃及把整条河谷纳入版图，苏丹以**自治领**形式并入埃及框架——名义上保留本地政府（NUP 执政），实质是埃及王国的直辖属土。阿兹哈里鼓吹了二十年的"统一"由此兑现，但代价立刻显形：对马赫迪阵营、对南方、对每一个把统一想象成伙伴而非臣属的苏丹人来说，这个词已经发酵成"吞并"的委婉语。曾经缝合两岸的标语，反倒成了割裂的刀痕。

**开局前十余年。** 1955 年托里特兵变，是南方裂痕的第一道口子；1956 年人民民主党（PDP）自 NUP 裂出，仍属哈特米亚阵营、却转向"苏丹优先"，成为阿兹哈里在亲埃统一派内部的潜在对手；1959 年阿卜杜勒·拉赫曼·马赫迪去世，其子萨迪克接掌安萨尔年轻一代，作风更伊斯兰民粹、更倾向草根动员，与保守地主派的旧乌玛党形成张力。英国这一昔日护盾消失后，反埃阵营失去外部靠山却并未归顺，只是把抵抗从议会搬进了教团、军营与南方丛林。

# 第三编　埃苏关系与区域格局

**一笔交易，两岸代价。** 1948 年埃意谅解把三件事捆在一起：意大利拿到运河区与基地的既成事实，埃及拿到整条尼罗河谷，苏丹失去选择权。开罗因此把"尼罗河谷统一"从宣传口号升级为行政现实；喀土穆则把同一个词读作吞并。这条不对称是埃苏关系的底层：宗主需要苏丹的棉花、岁入与尼罗河上游的水，苏丹需要宗主的投资、职位与安全，但双方对"我们是不是一国"的回答从来不同。

**三重榨取与三条裂缝。** 埃及从苏丹抽取的是棉花（杰济拉）、岁入（外销农业）与兵源／驻军合法性（SDF），却几乎不工业化这块臣属之地。裂缝也正好三条：北方教团政治（安萨尔拒绝归顺）、南方（被遗忘的赤道诸省）、军营（纳赛尔主义少壮军官）。纳吉布坐在总督官邸里，同时是这三条裂缝的连接点——他与开罗各党、与苏丹亲埃宪政派都有线，既可能是秩序的调解人，也可能是把所有不满串起来的那根引线。

**危机的传导路径。** 埃及链尾的苏伊士运河区游击战与意大利军事行动，会通过三条管道打到苏丹：运河受阻 → 棉花外运与外汇吃紧 → 杰济拉佃农契约与总督府财政同时绷紧；埃及抽调驻军 → 南方与安萨尔的压制力下降；开罗政局动荡 → 阿兹哈里与米尔加尼·哈姆扎的"苏丹优先"路线获得空间。原版石油危机（1970.11.13）与也门内战（1970.10.3）挤在同一季度，正好构成苏丹从"被管理"转向"被争夺"的窗口。

**纳赛尔主义的境外网络。** 1953 年流亡的纳赛尔、萨达特、毛希丁在本土已经出局，但他们的语言仍是整个地区反对派共享的词汇：叙利亚的萨拉杰在亲土政权内部握着情报机器，苏丹的尼迈里在军营里等机会，埃及本土的阿密尔与艾哈迈德·侯赛因分别占据军政府与法西斯槽位。 Designs 上应把这条线当作**一条潜伏的、跨国界的革命暗线**，而不是任何一个国家的主线剧情。

# 附录 B　建议新增的埃及专属民族精神（草稿）

目前 `common/ideas/` 下只有叙利亚（`tnoIPN_syria.txt`）与苏丹（`tnoIPN_rps.txt`），`tnoIPN_Assorted_Laws.txt` 里 EGY 的 `hidden_ideas` 是空的。建议为 EGY 增加五条，均只写**开局时点已成立的事实**，不预写后续事件：

1. **「阿卜杜勒·哈迪内阁与君臣裂痕」** — 西里病逝后，联合自由党失去仲裁者，萨阿德元老集团凭组织资历拿下首相；但首相与法鲁克在闭门会议里的冲突已成公开秘密，宫廷、议会与宗主三方各自等待一个体面的收场方式。建议 modifier：稳定小幅负、政治点数小幅正。
2. **「联合自由党的四派平衡」** — 萨阿德元老、政务系、思想系与技术官僚—自由学者共处一党，共享执政十余年的果实，也共享西里留下的空位；任何一次党魁更替都可能改写内阁的经济路线与对宫廷的距离。建议 modifier：保守／自由主义漂移、派系变量接口。
3. **「苏伊士运河区的阴影」** — 1948 年谅解把运河区留在意大利手里，换来了苏丹；此后每一届内阁都承诺收回，每一届都在罗马的底线前停住。运河是财政、是主权，也是埃及政治里最不能碰的那根神经。建议 modifier：贸易／政治点数修正，作为后期游击战的叙事接口。
4. **「一九五三年的记忆」** — 未遂政变后，自由军官的核心流亡海外，军方被置于王室与宗主的双重监视之下；军官团名义上忠于王国，私下仍有人在争论那次失败究竟输在哪里。建议 modifier：军队经验／稳定度、军政府路线触发接口。
5. **「意大利监护」** — 轴心胜利后的埃及并未真正独立：罗马握着运河区、基地与通商特权，开罗握着王冠与议会。宗主不直接统治，却决定哪几届内阁能活过一年。建议 modifier：`TRI_Member_Client` 的叙事化补充，外交／贸易修正。

# 附录 C　关键人物 DESC 补写草稿（仅开局时点，不预写后事）

- **易卜拉欣·阿卜杜勒·哈迪**：萨阿德主义制度党出身的政坛元老，联合自由党成立后成为萨阿德元老集团的领衔者。侯赛因·西里病逝、党内派系失衡之际，他凭资历与组织手腕接任首相，主张在君主立宪框架内维持秩序、与宫廷及意大利监护体系保持可管理的距离。其政府以稳健著称，却始终未能弥合与法鲁克之间的裂痕。
- **努雷丁·塔拉夫**：前萨阿德主义制度党出身的温和派技术官僚，长期在联合自由党内充任各派都能接受的过渡人选。以不结怨、不冒进见长，被视为在选举前维持政府运转的合适看守者，而非能重整党务的领袖。
- **福阿德·希拉吉丁**：华夫脱党传统派党魁、帕夏，党内旧世代的代表人物。主张在伊斯兰现代主义框架下恢复华夫脱党的执政地位，与宫廷关系素来紧张；其阵营内部还挤着数代思想与作风迥异的党员，胜选之后如何组阁本身就是难题。
- **法鲁克一世**：在位国王，埃及君主立宪秩序的中心。1947 年军需丑闻曾把王室推上风口，1948 年谅解又让王权与意大利监护绑定；他厌恶华夫脱党、警惕军方，也希望首相懂得分寸——这三条偏好几乎决定了每届内阁的寿命。
- **穆罕默德·阿卜杜勒·莫奈姆亲王**：王室旁支、前摄政人选，行事稳健而无独立政治班底，被视作王位过渡期最不惹争议的临时安排。其价值不在主张，而在血统与中立。
- **福阿德二世**：王位继承人，年轻、尚未亲政，宫廷与监护体系都把他当作"未来"而非"现在"来安排。谁在他成年之前掌着摄政与内阁，谁就握着埃及下一阶段的钥匙。
- **阿卜杜勒·哈基姆·阿密尔**：1953 年未遂政变后仍留在军中的自由军官，未随纳赛尔等人流亡。职业军人的履历与那段未竟的密谋同时贴在他身上，使他既是王室需要倚重的将领，也是安全部门名单上需要留意的名字。
- **艾哈迈德·侯赛因**：战前青年埃及党的创建者，埃及社会党的旗帜人物。主张以群众动员与民族复兴绕开议会与宫廷，其追随者与穆斯林兄弟会激进派、亲德派同处体制外的极右光谱，是监护秩序最不愿看到的动员方式。
